Cardinality

Cardinality defines the number of instances of one entity that can be associated with another entity. It indicates relationships such as One -to-One (1:1), One-to-Many (1:N), and Many -to- Many (M:N). For example, one Seller can list many Properties (1:N), one Property can have many Media assets (1:N), and one User can schedule multiple Site Visits (1:N).
